# 自然中文生成

用这个 reference 处理用户没有提供完整原文、只提供主题或要点，并要求写成“不像 AI”的中文内容。生成要比改写更克制，因为事实来源更少。

## 生成流程

1. 提取用户明确给出的事实、观点、场景、受众和用途。
2. 判断缺失信息是否会影响准确性。
3. 能直接写时，用用户给的信息组织成稿。
4. 信息不足但不影响表达时，写得保守，不补具体经历、数字或案例。
5. 信息不足且会影响事实时，先问一个必要问题，或给一个可替换占位表达。

## 写法原则

- 从具体问题、具体观察或直接观点开始，不从宏大背景开始。
- 保持正常人的信息密度：该具体时具体，该留白时留白。
- 不写“在当今时代”“随着社会的发展”这类万能开头。
- 不用“这不仅是……更是……”强行升华。
- 不把每个要点都写成整齐排比。
- 不为了自然虚构“我之前遇到过”“我有个朋友”等经历。
- 生活类内容不要只复述事实清单；可以加入轻微情绪、画面感、节奏感和照片配文感。
- 允许少量表情符号，但要符合平台和用户语气。

## 场景化生成

- 聊天：短，直接，像能发出去的一句话或几句话。
- 办公：清楚、准确、可执行，保留必要结构。
- 社交：有具体切入点，避免营销号套话。
- 朋友圈：像配图文案，不必完整交代前因后果；可以短、松、带一点情绪。
- 学术：保留概念和限定，不口语化，不编文献。

## 输出

用户只要成稿时，直接给正文。需要说明时，最多补一句：

```text
我按你给的要点写得更克制一点，没有补额外经历和数据。
```
