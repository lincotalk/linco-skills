# 去 AI 味改写

用这个 reference 把诊断结果转化为自然中文。改写的第一原则是保留事实、意图和场景功能，其次才是语气自然。

## 改写顺序

1. 提取原文事实：人物、时间、动作、条件、结论、限制。
2. 判断必须保留的结构：标题、条目、流程、数字、责任人、引用。
3. 删除空泛铺垫、机械转折和强行总结。
4. 把抽象判断换成具体说法。
5. 调整句长、节奏和松散度。
6. 社交/日常文本需要更像真人时，读取 `human-looseness.md`，允许一点不那么精致的表达。
7. 观点文、笔记文、社交长文需要避免内容号模板时，读取 `anti-content-template.md`。
8. 按场景套用语气标准。
9. 用 `final-check.md` 复查。

## 改写力度

### light

适合用户说“轻微润色”“别大改”“保留原文结构”。

- 保留原段落顺序。
- 只删明显套话和重复表达。
- 小幅调整句式，让话更顺。
- 不新增观点。

### medium

默认力度。

- 可以合并、拆分、重排部分句子。
- 可以把空泛概念换成更具体的表达。
- 可以调整开头和结尾。
- 保留核心事实和主要结构。

### heavy

适合用户说“重写”“完全换一种说法”“像真人重新写”。

- 可以重新组织段落。
- 可以改变表达路径。
- 可以删掉大部分模板结构。
- 不改变事实、立场和承诺。

## 常用改法

- 宏大开头 -> 具体场景开头。
- 万能总结 -> 具体结论或直接停住。
- 抽象价值 -> 可观察的动作、结果或感受。
- 机械连接词 -> 自然承接或直接并列。
- 过度客观 -> 根据场景加入有限主观判断。
- 长句堆叠 -> 拆成短句，并保留必要逻辑。
- 过度精准 -> 加入少量真人写作里的缓冲词、模糊词和轻微重复。
- 完美并列 -> 改成像想到哪里说到哪里的自然推进。
- 内容号模板 -> 打散“反常识标题 + 编号解释 + 普通人启发 + 金句收尾”，改成真实观察、过程感和不完全对称的段落。

## 事实保护

改写前先默记这些不可碰内容：

- 数字、日期、地点、姓名、机构名、产品名。
- 承诺、要求、限制、风险提示。
- 用户立场和情绪强度。
- 原文中的因果关系。

如果原文信息不足，不要补故事、补数据、补经历。可以把模糊表达改得更清楚，但不要发明内容。

## 输出方式

用户没特别要求时：

```text
改写版：
...

我主要改了三处：...
```

说明最多 3 条。聊天、朋友圈、短文本场景可以省略说明。

## 禁止改法

- 不把所有文本都改成“其实吧”“怎么说呢”。
- 不故意加错别字、网络烂梗或夸张口癖。
- 不把办公文本改得过度随意。
- 不把社交文本写成营销号模板。
- 不为了显得自然而加入用户没有说过的私人经历。
- 不把每句话都压缩到最优表达；小红书、朋友圈、随笔可以保留一点“说话时绕一下”的感觉。
- 不让每个小标题都长成“X 不是 A，是 B”；这种句式最多保留 1 处。
