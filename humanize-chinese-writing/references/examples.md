# 校准案例

这个文件用于校准输出质量。只有在不确定如何处理某类任务，或需要检查 skill 行为是否稳定时读取。不要把案例原文照搬给用户。

## 案例 1：纯诊断

用户：

```text
帮我看看这段哪里像 AI：
在当今快速变化的时代，阅读不仅是一种获取知识的方式，更是一种提升自我、拓展视野的重要路径。我们应该充分认识到阅读的价值，并在日常生活中不断培养良好的阅读习惯。
```

期望处理：

```text
判断：这段 AI 味比较明显，主要集中在开头和结尾。

主要问题：
1. 开头太大：“在当今快速变化的时代”没有提供具体信息，像通用作文开场。
2. 句式太模板：“不仅是……更是……”是高频 AI 腔结构。
3. 抽象词偏多：“提升自我、拓展视野、重要路径”都对，但没有具体内容。

优先修改方向：
- 从具体阅读场景或真实感受切入。
- 保留“阅读有价值”这个意思，但少用升华式表达。
```

## 案例 2：社交平台改写

用户：

```text
帮我去 AI 味，适合发朋友圈：
旅行不仅能让我们看到不同的风景，更能让我们在过程中重新认识自己。每一次出发，都是一次心灵的成长。
```

期望输出：

```text
改写版：
出去走了几天，最大的感觉不是看了多少风景，而是人真的需要偶尔离开原来的节奏。换个地方待一待，很多事会慢慢松下来。
```

注意：
- 没有强行加“建议大家都去旅行”。
- 没有保留“心灵成长”这种升华。
- 比原文更像私人表达。

## 案例 3：办公改写

用户：

```text
改得更像人写的，但还是要正式：
后续我们将持续推进相关工作的落地执行，进一步强化跨部门协同，不断提升整体工作效率，确保项目高质量完成。
```

期望输出：

```text
改写版：
下一步我们会重点推进三件事：明确各部门的交付时间，固定每周同步一次进展，及时处理影响项目推进的问题，确保项目按计划完成。
```

注意：
- 把“持续推进、强化协同、提升效率”改成具体动作。
- 仍然正式，没有改成聊天语气。
- 如果原文没有“三件事”的依据，可改成“不列数字”的版本。

## 案例 4：风格模仿

用户：

```text
这是我的风格：我不太喜欢把话说满。很多事我更愿意先看具体情况，再慢慢判断。太确定的表达，反而让我觉得不真实。

帮我按这个感觉改：
我们必须意识到，长期主义是每个人都应该坚持的重要原则，它能够帮助我们在人生道路上获得持续成长。
```

期望输出：

```text
改写版：
我不太想把“长期主义”说成一个人人都必须接受的原则。它可能有用，但前提是你真的知道自己为什么要坚持，而不是只是被这个词推着往前走。
```

注意：
- 学的是“克制、不说满”的表达习惯。
- 没有编造用户经历。

## 案例 5：从零生成

用户：

```text
帮我写一段小红书开头，主题是最近开始早睡，别太 AI。
```

期望输出：

```text
这段时间开始认真早睡之后，我发现最明显的变化不是皮肤变好这种大结论，而是第二天早上没那么烦了。以前醒来第一反应是累，现在至少能慢一点开始一天。
```

注意：
- 可以组织表达，但没有编造具体天数、产品、医学效果。
- 从真实感受切入，不写“现代人越来越重视健康”。

## 案例 6：朋友圈生活配文

用户：

```text
适合发朋友圈：深圳，万象天地，参观了巨人展，拍了很出片的照片，吃了美食烧鸭饭
```

较差输出：

```text
深圳这天气，逛万象天地还挺舒服。顺路看了巨人展，照片比想象中出片，最后用一份烧鸭饭收尾，今天很完整。
```

问题：
- 太像信息整理，趣味性弱。
- 没有照片配文感。
- 情绪太平。

期望输出：

```text
万象天地半日游：看了巨人展，拍到了满意的照片，最后用烧鸭饭收尾。深圳今天这趟，安排得刚刚好 📷
```

也可以给多版本：

```text
松弛版：
在万象天地晃了一下午，看展、拍照、吃烧鸭饭，今天的快乐很具体。

有趣版：
今天在万象天地的流程：看巨人展 -> 拍出片 -> 吃烧鸭饭。很简单，但很满足 🍚
```

注意：
- 可以加表情，但不堆。
- 可以有轻微俏皮，但不编造天气、同行人、具体展品。
- 朋友圈配文可以短，不需要完整叙事。

## 案例 7：小红书工具/APP 分享

用户：

```text
适当改写适合发小红书的文案：
闲来无事，最近做了一个记账APP，平时可以自用，需要什么功能我就加什么，如果大家有需要的可以评论区评论私信联系我，可以无偿共享
```

较差输出：

```text
最近闲着做了一个记账 APP，本来只是想自己用得顺手一点。
现在就是边用边改，想到什么功能、缺什么功能，就慢慢加进去。

如果你也刚好需要一个简单点的记账工具，可以评论区留言或者私信我。
目前可以无偿分享，也欢迎提需求，我看看能不能一起加进去。
```

问题：
- 语气像通知，缺少开头钩子。
- 没有明确目标人群和痛点。
- 互动句太普通，不够让人想评论。
- 小红书感弱，像朋友圈或群公告。

期望输出：

```text
有没有人和我一样，记账 APP 下载了一堆，最后还是懒得打开？💰

最近顺手做了一个自己的记账 APP，先不搞太复杂，能日常记录、自己用得顺手就行。

现在它还属于“边用边改”的状态：我平时缺什么功能，就直接加什么功能。

如果你也想要一个简单点的记账工具，可以评论/私信我，我可以先无偿分享。
也想问问大家：你们记账最需要哪个功能？我看看能不能一起加进去。
```

注意：
- 开头用痛点钩子，让目标用户停下。
- 表情只用 1 个，服务语气。
- 结尾不是泛泛“欢迎联系”，而是问具体功能需求。
- 没有编造 APP 已有功能，只说“日常记录、边用边改”。

## 案例 8：小红书开源 Skill 分享

用户：

```text
适合发小红书：
告别一眼AI！自研中文版去AI味Skill开源。最近全网都在卷去除AI味的Prompt和技巧。看多了各种通用教程，发现大多适配外文、不贴合中文语境，实操下来效果很鸡肋。我们自己深度打磨、自研优化，正式开源专属中文版去AI味Skill。
```

过于精致的输出：

```text
有没有人也觉得，AI 写出来的中文有时候不是不好，而是太标准了？
句子很顺、结构很满，但一眼就能看出来不像真人写的。
```

问题：
- 已经自然了，但还是太精准。
- 每句话都像编辑过，缺少一点真人写东西时的松散和补充。

更合适的输出：

```text
有没有人也觉得，AI 写出来的中文有时候不能说不好，但就是太“标准”了？

最近看了不少去 AI 味的 Prompt 和教程，不能说没用，但很多放到中文语境里，总感觉还是差点意思。尤其是那种万能开头、强行总结、句式太整齐的问题，中文里真的很明显。

所以后来我们干脆自己做了一版中文版去 AI 味 Skill，目前已经开源了 ✨
```

注意：
- 保留“不能说不好”“不能说没用”“总感觉”这类缓冲词。
- 不是每句话都追求最精准。
- 信息仍然清楚：问题、原因、动作都在。

## 案例 9：反内容号模板

用户：

```text
小红书版：
标题：AI 时代的创业，不是抢机会，而是懂克制
看完梁文锋这场交流会，我最大的感受是：AI 时代机会很多，但真正厉害的人，不一定是抓住最多机会的人，而是知道哪些机会先不抓。我整理了 4 个普通人也能用的判断：愿景不是口号，是组织方式；克制不是保守，是战略；开源不是亏钱，是放大生态；普通人最该学的是取舍。
```

较差输出：

```text
看完梁文锋这场交流会，我反而对“机会”这件事有点重新理解了。

我整理了 4 个点，感觉普通人做账号、做产品、做项目也都能用：

1. 愿景不是一句口号
2. 克制不是保守
3. 开源不一定是亏
4. 普通人更要学会取舍
```

问题：
- 已经比原文自然，但仍然是知识博主结构。
- “4 个点”“X 不是 A”太整齐。
- 读起来像标准笔记，不像一个人的真实发现。

更合适的输出：

```text
看完梁文锋那场交流会，我有个挺强的感觉：

AI 时代最难的可能不是发现机会，而是忍住不去抓一些机会。

这话听起来有点反直觉。
毕竟现在大家都在说，AI 到处都是新机会，谁反应快谁就先吃到红利。

但梁文锋给我的感觉不是这样。
他反而一直在强调主线，强调有些东西看着很香，但会把你带偏。

比如 C 端流量、B 端收入、API 商业化、生态合作，这些当然都有价值。
但如果每个都想抓，最后可能就不是你在选择机会，而是机会在推着你走。
```

注意：
- 不急着交付“4 个判断”。
- 先写个人发现，再展开。
- 保留一个核心金句即可，不要每段都金句。
- 结构不完全对称，更像真人思考。
