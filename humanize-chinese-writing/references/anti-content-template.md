# 反内容号模板

用这个 reference 处理“虽然不像 AI 套话，但像知识博主/观点号标准模板”的问题。适用于小红书观点笔记、公众号文章、读后感、会议笔记、创业/AI/认知类内容。

## 模板味信号

出现这些结构时要警惕：

- 反常识标题：`不是 X，而是 Y`
- 标准开头：`看完...我最大的感受是`
- 整齐分点：`我整理了 4 个判断`
- 小标题统一句式：`X 不是 A，是 B`
- 普通人启发：`普通人最该学的是...`
- 三问收束：`这是我的主线吗？会不会拖慢我？能不能长期做？`
- 金句结尾：`真正拉开差距的，可能不是...而是...`

这些写法不是不能用，但如果同时出现 3 个以上，读起来会像内容号模板。

## 改写方向

### 1. 从“交付结论”改成“呈现发现”

不要一开始就把观点说满。先保留一点观看、阅读、理解过程：

```text
我本来以为这场交流会最值得看的是 DeepSeek 怎么做商业化。
但看完反而觉得，不是。
```

### 2. 降低分点的工整度

如果原文有 4 点，不一定保留 4 点。可以改成：

- 先讲 1 个最重要的发现。
- 再补 2-3 个旁支观察。
- 或者保留分点，但让小标题不完全对称。

避免每一点都写成：

```text
X 不是 A，是 B
```

### 3. 降低金句密度

全文最多保留 1-2 句有金句感的话。其他地方写得朴素一点。

过于金句：

```text
AI 时代真正拉开差距的，可能不是谁更会追热点，而是谁更懂取舍。
```

更像真人：

```text
到最后可能还是看谁能少被机会带着跑。
```

### 4. 允许局部不完整

真实文章不需要每段都有完整结论。可以让某些段落停在感受、疑问或小判断上：

```text
这点其实挺难的。因为很多机会不是不好，它只是会把你带到另一条路上。
```

### 5. 用具体句替代概念句

把“战略、主线、生态、取舍”这类概念落回动作：

```text
今天想做 API 收入，明天想追 C 端流量，后天又觉得生态合作也该试试。
忙是忙了，但主线可能就散了。
```

## 场景区分

- 小红书：更像个人笔记，保留松散和互动；少一点课程大纲感。
- 公众号：可以保留结构，但别每段都是结论；给读者看到推理过程。
- 短视频口播：用短句和反差，不用完整论文结构。

## 复查问题

输出前问：

1. 这篇是不是太像“知识博主标准稿”？
2. 有没有连续多个“不是...而是...”？
3. 有没有每段都在交付结论？
4. 有没有普通人启发、三问、金句收尾同时出现？
5. 有没有一段像真人临场想出来的话？

如果前 4 个答案是“是”，必须打散结构。第 5 个答案如果是“否”，加一点真实思考过程。
