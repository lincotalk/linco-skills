# Prompt Examples

Use these examples as starting points, then replace the bracketed details with observations from the supplied photo. Keep the top half photographic and the bottom half a recognizable reinterpretation of the same subject.

## Street Scene

```text
Create one premium 3:4 vertical editorial poster with an exact horizontal 50/50 split.
TOP HALF: preserve the photographed red tram, wet street, overhead wires, and overcast evening light as realistic photography.
BOTTOM HALF: keep the red tram recognizable on a warm off-white paper field. Reinterpret the scene as a quiet crossing, with tiny fine-line people waiting, walking, and holding umbrellas. Use brick red, slate blue, muted green, and cream. Add sparse handwritten copy: QUIET CROSSING.
No collage, borders, logos, watermark, or extra readable text.
```

## Review Checklist

- Replace every bracketed detail with source-specific observations.
- Request authorization before sending an identifiable person's photo to an external endpoint.
- Keep copy short, sparse, and limited to the requested phrase.
- Verify the generated file and visually inspect the split before delivery.
